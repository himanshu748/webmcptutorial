01 About

I'm a computer-science student who loves turning AI ideas into things people can actually click. Most of my projects live in the browser or run on small, honest backends — no magic, just Python, JavaScript, and a lot of curiosity.

Lately I've been fascinated by AI agents and a simple question: if agents are starting to browse the web, why do we still make them guess their way around our sites? This portfolio is my answer — it exposes clean, structured tools an agent can call, using the emerging WebMCP approach. I also enjoy writing beginner-friendly tutorials, because the best way to learn something is to teach it.

04 AI agent tools

This page registers real WebMCP tools on navigator.modelContext (via the @mcp-b/global polyfill), so an AI agent — through the WebMCP browser extension or Chrome's native support — can call them directly.
